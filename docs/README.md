规矩（与本系列其他仓库一致）：

- 预览图**只用示例数据**：仓库自带的「示例博客 / 示例文章」即可，绝不把自己站点的真实文章、真实评论、真实用量、真实域名与账号截进去。
- 图片引用统一走 jsdelivr 镜像：`https://gcore.jsdelivr.net/gh/<你的账号>/ym-blog@main/docs/<文件名>`（国内网络直连 GitHub 图床不稳，镜像更可靠）。
- 重拍时沿用同一套做法：本地灌种子数据渲染（渲染脚本口径同 `scripts/smoke.mjs` 的宿主），桌面 1280 宽、手机 390 宽；后台页必须经 http:// 本地服务打开再截（file:// 下接口请求会被浏览器拦截，只剩骨架屏）。
- 单张图片尽量压在 500KB 以内；页面空白大时按内容裁高，不要留大片白边。
